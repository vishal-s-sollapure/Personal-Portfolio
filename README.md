# 🚀 Vishal S Sollapure — Interactive Developer Portfolio

A modern, high-performance, and interactive developer portfolio built with **React**, **Tailwind CSS**, **Framer Motion**, and **Gemini API**. Designed to highlight full-stack web development projects, AI/GenAI applications, and technical experience.

![Portfolio Banner](https://raw.githubusercontent.com/vishal-s-sollapure/portfolio/main/public/profile.jpg)

---

## ✨ Features

- 🎨 **Dark Neon Aesthetic:** Custom dark-mode theme featuring cyan and violet gradients.
- ⚡ **Lightning Fast:** Built with Vite and React for instant page loads and seamless routing.
- 📱 **Fully Responsive:** Designed mobile-first, supporting mobile, tablet, and desktop viewports.
- 🤖 **Interactive AI Assistant:** Integrated chatbot interface powered by Gemini API to answer recruiter questions about skills, resume, and experience.
- 📊 **Skills Matrix:** Categorized technical stack covering Frontend, AI & GenAI, Databases, and DevOps tooling.
- 💼 **Interactive Timeline:** Chronological timeline showcasing software development internships and educational background.

---

## 🛠️ Tech Stack

- **Frontend:** React.js, Tailwind CSS, JavaScript (ES6+), Framer Motion, Lucide Icons
- **AI & GenAI:** Gemini API, RAG Architecture, Python, Prompt Engineering
- **Build & Deployment:** Vite, Vercel, Git, GitHub
